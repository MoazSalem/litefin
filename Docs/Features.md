# Features

Litefin has evolved through over 300 technical milestones. Below is a categorized list of implemented functionality.

## Media & Browsing
- **Comprehensive Library Support**: Movies, TV Shows, and Music libraries.
- **Music Experience**: lyrics support, personalized suggestions, and dedicated Artist/Album grids.
- **Rich Metadata**: Advanced Details page with metadata, cast/crew (Person pages), studios, and genres.
- **Search**: Debounced, real-time search across all libraries.
- **Favorites**: Centralized management for favorite items across libraries.

## Interactive & Social
- **SyncPlay**: Watch media in sync with others via server-side WebSockets.
- **Intro/Recap Skipping**: Automatic detection and skip controls for TV show segments.
- **Screensaver**: Ported from Jellyfin Web with dimming and title-hide options.
- **Server Discovery**: Automatic local server discovery and manual connection flows.

## Player Enhancements (OSD)
- **Modular OSD Design**: Multi-layer interface supporting advanced controls.
- **Chapter Selection**: Navigate media via internal chapters.
- **Quality Switching**: Dynamic bitrate and resolution selection during playback.
- **Playback Info**: Real-time stats showing transcode reasons and codec details.
- **Queue Management**: Shuffle, repeat, and "Up Next" dialogs for continuous watching.

## Technical Milestones
- **Dual Player Backends**: Intelligent switching between native hardware and HTML5.
- **Translation Engine**: Support for multiple languages and RTL layouts.
- **Customization**: App-wide font overrides, rounded corner toggles, and advanced theming.
- **Debugging Suite**: Centralized logging with the ability to report logs directly to the server.
